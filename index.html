Start here

Turns scattered newspaper clippings into evidence. Runs on your own computer — no account, no cost. Your data stays on your machine.

Four steps, start to finish

  1. Build a corpus. Fetch → preset → Build my corpus. Searches, downloads text, sorts, names performers and maps them. Stop and resume any time.
  2. Weed out false hits. Not every “whistle” is a person. Library → Review…: Keep, Not about whistling, Unsure.
  3. Explore. Search with the context slider, then Map, Network, Trends and Performers.
  4. Write it up. Report builds a paper with a Works Cited — print, PDF or Word.

Before you close: click Export JSON. That one file is your backup and how you move the archive to another computer.

New here? Replay the guided tour. Prefer to run the stages separately? They're under Advanced on the Fetch tab.

Put it on your Desktop (Windows)

  1. Right-click the downloaded ZIP → Extract All… (don't run things from inside the ZIP).
  2. Open the extracted folder and double-click Install Whistling Archive.
  3. Windows asks once if you're sure — choose Run. That question never comes back.
  4. A Whistling Archive icon appears on your Desktop. Open it like any program.

The one-time question is just Windows being careful with downloaded files. Nothing is installed and nothing moves — the icon simply opens the Workbench in its own window. On a Mac: open index.html in your browser and choose File → Add to Dock.

Read this Why some of the text looks like gibberish

Nothing is broken — this is normal. These papers were microfilmed decades ago, then read by a computer (OCR). Where the paper was stained or faded it guesses wrong:

What the scanner produced 1 i 1 1 r-1 lf:it I ti.r N-'-TT-M WW Powders Leiads? 106 WALL ST., NEW-YORK. TWENTY WHISTLING GIRLS. They Warble In San Francisco …
What this workbench shows you … TWENTY WHISTLING GIRLS. They Warble In San Francisco, and Each Possesses a Rosebud Mouth …
  • It picks the clearest passage on each page — so you see the sentence, not the speckle.
  • If a page is too damaged, it says “Scan too unclear to preview” instead of printing nonsense.
  • The original is one click away. Open a record → view original page ↗ for the real scan.
  • Nothing is deleted. The full text is kept as received; only the little preview is tidied.

In short: messy preview text is a property of 120-year-old newsprint, not a bug. If a record matters to your argument, open the original page and read it there.

For instructors — preparing & sharing a class set

  1. Build it once: Fetch → pick a preset → Build my corpus (search, text, categories, performers and map places in one run).
  2. Clean it: Library → Review… to drop the false hits before students ever see them.
  3. Save collections (Library → “Save view as collection”) to give each assignment its own focused subset.
  4. Share one file: Settings → Save as class dataset…, then send that file plus index.html. Students open it from the Home tab.
  5. Lock a shared machine: Settings → Teaching → Classroom mode hides Clear all, delete and import.
  6. Works offline in a lab. No internet or AI key needed once the dataset is shared.
  7. Free for students. No API key, ever. AI is an optional upgrade.

Keep a master JSON backup. Students work on their own copy, so yours is safe.

For scholars — the method apparatus

Reviewers argue with method, not charts. These five features answer the five questions a referee asks.

Corpus manifest & freeze — “Where did this data come from?”
Freeze corpus version records what the corpus held on a given day, so a figure traces to a fixed snapshot. Export citable bundle adds a citation and Zenodo steps for a DOI.
Reproduce from manifest — “Could anyone else get your results?”
Hand someone the manifest and Reproduce from manifest loads your exact query into their Fetch tab. The archive is public, so it genuinely re-runs.
Accuracy audit — “How wrong is it?”
Library → Audit… walks a random sample, asking if each record is really about whistling and if its category is right. Reports both percentages and writes the methods sentence for you.
Inter-coder reliability — “Is the coding scheme reproducible?”
Export audit packet makes a blind packet; two people Code a packet separately; Compare two codings reports agreement and Cohen's κ. κ discounts lucky guesses, so both are shown.
Baselines — “Didn't everything rise in the 1890s?”
Counts control terms over the same archive, so you compare the shape of whistling's curve against banjo or cornet — not a rise that just reflects more digitised pages.

The Report assembles all of this automatically. Where a measurement hasn't been made, nothing is printed — it never claims rigour it doesn't have.

Assignment sheets (ready to hand out)

Graded exercises that work on any class dataset. Students need only the file and this page.

1 · Trace a tour (Map)

  1. Open the class dataset (Home → Open a class dataset).
  2. Go to Map and choose one performer from the Tour dropdown — e.g. Alice Shaw or Margaret McKee.
  3. Write down the cities in date order, then click two of them to read the underlying articles.
  4. Submit: the route, the years it spans, and one paragraph on what the geography suggests about how the performer built a career (regional circuit? big-city only? coast-to-coast?).

2 · What counts as a whistle? (Trends + Library)

  1. In Trends → Category mix, note which sound-types dominate each decade.
  2. In the Library, filter to one category and open five records; use Review… if you'd rather step through them.
  3. Re-categorise any record you think is mis-tagged, and write a note in each saying why.
  4. Submit: your five records (Settings → Export my findings) plus a paragraph on where the line between literal sound, metaphor, and performance is genuinely hard to draw.

3 · Cite the evidence (Search + Cite)

  1. Search a term such as siffleuse and widen the context window to 50 or 100 words.
  2. Choose three mentions that support one claim about whistling as a serious art (or as mere novelty).
  3. Open each record and click Copy citation; paste them into your document.
  4. Submit: a one-page argument with three properly formatted newspaper citations and a sentence on what each source can — and cannot — prove.

4 · Do we agree on what we hear? (paired coding)

Works in pairs. The instructor prepares one packet (Settings → Export audit packet…) and gives the same file to both partners.

  1. Each partner separately: Settings → Code a packet…, choose the file, and assign a sound-type to every record. Neither of you can see the computer's category, or each other's.
  2. Export your coding and give both files to your instructor (or to one partner), then run Compare two codings….
  3. Note the raw agreement and Cohen's κ. κ discounts lucky guesses, so it's usually lower — that gap is informative, not an error.
  4. Look at the records you disagreed on and decide, together, what the right answer is and why the boundary was unclear.
  5. Submit: your κ, and one page on two specific disagreements — what makes each case genuinely ambiguous, and how you would sharpen the category definition to resolve it.

The disagreements are the point. Every one marks a place where the category scheme meets a real interpretive problem — that argument is the musicology.

Further discussion questions

  • Pick a performer and reconstruct their tour from the Map — which regions did they favor, and how did that change by decade?
  • Using Search + the context slider, find five mentions and classify each as person / weather / machine / bird / metaphor. Where is the line blurry?
  • On the Network, find two whistlers linked by a shared newspaper or city. Open the source articles — is it a real connection?
  • In Trends, compare the rise of two terms (e.g. siffleuse vs whistler). What does the vocabulary shift suggest?
  • Argue, with evidence from the archive, whether whistling was treated as popular entertainment or serious art — and whether that changed.

Glossary

Siffleur / Siffleuse
French for a male / female whistling performer — common 19th-century billing.
Chronicling America
The Library of Congress's free, public-domain collection of historic U.S. newspapers (1836–1922) that this tool searches.
OCR
Optical Character Recognition — software reading the text off a scanned page so it can be searched.
Scanner noise
The stray marks OCR leaves in otherwise good text — see “Why some of the text looks like gibberish” at the top of this Guide.
Sound-type category
Whether a “whistle” mention is a person, wind/weather, train/machine, bird, performance, etc.
Epithet
A performer's stage nickname (e.g. “the California Siffleuse,” “King of Whistlers”).
Gazetteer
The list of cities → coordinates used to place records on the map.
